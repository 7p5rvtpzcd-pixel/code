# 代码台 —— 在浏览器里写 C / C++ 的小工具

打开就是编辑器，点运行用真的 gcc 14 编译执行。给同学做题、验算、对拍用。

**线上地址**：<https://7p5rvtpzcd-pixel.github.io/code/>

手机上用 Safari 打开 → 分享 → 添加到主屏幕，就像个 App。

## 能干什么

| 功能 | 说明 |
|---|---|
| 写 C / C++ | 顶栏切换语言；行号、语法高亮、Tab 缩进、括号配对、`Ctrl/⌘+Enter` 运行、`Ctrl/⌘+S` 保存 |
| 模板库 | 快读、二分、并查集、DFS、结构体排序，一点载入，**连示例输入都填好** |
| 输入 | 左边写代码，右边「输入」框里粘测试数据，程序里的 `cin`/`scanf` 从这里读 |
| 判定 | 填「期望输出」，跑完自动判 `✓ 一致` / `✗ 不一致` |
| 编译报错 | 翻成「行号 + [错误] + 源码行」，点行号跳过去（C 的 `main.c` 也认） |
| 测试用例 | 存多组输入/输出，一键全跑 |
| 随机对拍 | 写「生成器 + 暴力 + 解法」，跑 N 组随机数据，不一致自动存成用例 |
| 提交历史 | 最近 30 次运行记录，点一条能恢复当时的代码 |
| 分享 | 点「分享」把代码+输入压进链接发出去 |
| 题目笔记 | 存题面和样例，能自动提取「样例输入/输出」 |
| 数据备份 | 「数据」按钮里导出 `.json` / 导入恢复 / 清空全部 |
| 左右分栏 | 中间那条分隔条可以拖动，双击回到默认宽度（记住你的选择） |
| 深浅色 | 顶栏切换 |

### 判定严格度（行尾空格）

「期望输出」旁边有个下拉：

- **宽松**（默认）：忽略行尾空格 —— 绝大多数题都这样
- **严格**：行尾空格也算 —— 图形题、要精确输出的字符串题

宽松模式下如果你的输出和期望只差行尾空格，会提示「第 N 行末尾多了 X 个空格」，
说明这题要是严格判就会 WA，切到「严格」再确认一次。

### 提样例能认哪些写法

把题面粘进「题目笔记」，点「从笔记提取样例」。认这些标题：

```
输入 #1 / 输入 #1复制      输出 #1 / 输出 #1复制
样例输入 / 样例输入 #2       样例输出 / 样例输出 #2
输入样例 1                  输出样例 1
Sample Input 1              Sample Output 1
```

`输入格式` / `输出格式` / `说明` / `提示` 会自动跳过，不会被当成样例数据。
**块中间的空行会保留**（有些题的样例输出本身带空行），开头和结尾的空行会去掉。

改完提取逻辑可以本地验：`node tests/extract-test.js`

## 怎么跑起来的

- **不用建服务器**：纯静态页面，几个 HTML/CSS/JS 文件，扔在任何静态托管上就能用
- **真编译**：代码发到 [Judge0](https://judge0.com/) 的公共实例，C++ 用 gcc 14 的 C++ 模式（`language_id 105`），C 用 C 模式（`103`），编译执行后再把 stdout 传回来。所以要点才等 3 秒，而且要联网
- **编辑器**：CodeMirror 5（已经打包在 `vendor/` 里，不依赖外网 CDN）

所以：

- 你的代码**会离开浏览器**，发到第三方服务器
- 每个访客的数据（代码、用例、历史）存在**他自己浏览器**里，互不相通

## 自己改

```powershell
# 本地跑起来看效果
node ..\serve-web-code.js --port 8080
# 然后浏览器打开 http://127.0.0.1:8080/
```

改完直接改这几个文件，推上去 GitHub Pages 会在 1 分钟内自动更新。

| 文件 | 管什么 |
|---|---|
| `index.html` | 页面结构 |
| `app.css` | 样式（含深/浅色） |
| `app.js` | 全部逻辑：运行、判题、对拍、历史、分享、提样例、模板 |
| `samples.js` | 内置示例 + 对拍默认的生成器/暴力（按 C/C++ 分开） |
| `templates.js` | 模板库（按语言分开，带示例输入） |
| `vendor/` | CodeMirror，不用动 |

## 限制

- 依赖 Judge0 公共实例：有速率限制，偶尔会慢或挂
- 每个程序 1 秒 / 128MB 上限（可切到 2s / 5s）
- 对拍每组要跑两次云端，10 组大约 10 秒
- 模板库里的「快读」在没给输入时会读到 EOF 直接返回，不会死循环
- **数据只存在浏览器里**：清缓存 / 换设备 / 隐私模式会丢，靠「数据 → 导出备份」自己存一份
- **输出超过 200 行（或 4 万字符）只显示开头**，判题用的仍是完整输出（防止大输出卡死页面）
